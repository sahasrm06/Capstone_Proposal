# Capstone interim analysis

This package reproduces real-data analysis for the approved PCB false-call project. No raw source records are redistributed. Source notices and attribution are in project/data/. The fitted model and derived outputs are included.

1. Extract this ZIP into a new folder. Create a Python 3.12 environment and install requirements_full.txt.
2. Download dataset.csv and mapping.json from https://data.mendeley.com/datasets/99jzmh9658/2 and place both under project/data/raw/. Do not alter the originals.
3. From the extracted root, run `python project/scripts/audit_data.py` and `python project/scripts/sample_sizes.py`.
4. Run `python analyze_full.py`. This runs all 14 candidates and three chronological folds, then fixes the selected model and threshold before primary test evaluation. It overwrites full_results/ and can take several minutes on a CPU. Use OPENBLAS_NUM_THREADS=1 and OMP_NUM_THREADS=1 to reproduce thread settings.
5. Run `python robustness.py` and `python export_model.py`. The export deterministically refits the frozen selected specification, verifies that all primary test scores reproduce, and saves the estimator and descriptive training importance. It does not select another rule.

The group_data.csv and test_predictions.csv outputs contain timestamp-group derived data, not the original inspection rows. Fields `score` and `retain` are frozen model output; `y` is group outcome. The `gid` column is the stable timestamp-group index. day uses active-day order, not elapsed calendar days.

The report's main conclusion is that ordinary Wilson intervals meet the research cutoffs, but day-block avoidance uncertainty does not establish avoidance above 10%. Manual review remains the recommendation. The 10 missed positive groups are explicitly reported.

The source GitHub repository has NOT been changed. For GitHub submission, merge the new analysis scripts, requirements, dictionary, source manifest, and desired results into your repository, preserving the source attribution and ignoring raw files. Do not publish raw files without permission. The repository snapshot in this ZIP is only a starting point.

Loading joblib files executes Python serialization; use only this model generated by the supplied analysis, in the pinned environment. Feature importance is a training split-gain diagnostic for the selected histogram booster, not a causal result. The metadata-only validation comparison is secondary. Duplicate sensitivity preserves the primary fitted rule; model retraining after deduplication is future work.
